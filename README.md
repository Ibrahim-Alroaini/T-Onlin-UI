# T-Onlin — نموذج أولي لإدارة التعليم

نموذج ويب تفاعلي ثنائي اللغة (العربية RTL / English LTR) لمنصة إدارة التعليم. يحافظ على الهوية الأكاديمية الخضراء والبطاقات الهادئة المرجعية، ويضم مساحات مالك المنصة ومدير المؤسسة والمنسق الأكاديمي والمعلم والطالب وولي الأمر وموظف الدعم.

## تشغيل محلي

يتطلب Node.js 22 وpnpm 10.12.1.

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

لإنشاء النسخة الثابتة التي يعمل بها GitHub Pages:

```sh
VITE_BASE_PATH=/T-Onlin-UI/ pnpm build
```

## تجربة النموذج

افتح `/` للصفحة العامة، ثم اختر **تسجيل الدخول** وحدد الدور المطلوب قبل المتابعة. لا توجد مصادقة حقيقية: أدخل بريدًا تجريبيًا غير فارغ، وكلمة المرور المعروضة مسبقًا هي `demo1234`. يمكن أيضًا تغيير الدور من قائمة الحساب. تظهر شارة «بيانات تجريبية» داخل الواجهات.

المشروع واجهة أمامية فقط. لا يتصل بقاعدة بيانات أو بريد أو دفع أو مزود فيديو؛ أزرار الحفظ والتصدير والانضمام تحاكي حالة الواجهة محليًا. لا تستخدم هذه البيانات لاتخاذ قرارات أو رفع بيانات شخصية حقيقية.

## النشر على GitHub Pages

ينشر الملف `.github/workflows/pages.yml` مجلد `dist/` باستخدام GitHub Actions عند كل تحديث لفرع `main`. بُنيت أصول Vite لمسار المشروع `/T-Onlin-UI/`، ويعيد `public/404.html` تمرير المسارات العميقة إلى التطبيق. بعد نجاح أول Workflow، تكون الصفحة على:

<https://ibrahim-alroaini.github.io/T-Onlin-UI/>

يوضح `public/manus-routes.json` مسارات الصفحات (بما فيها أنماط المسارات الديناميكية) للمراجعة الآلية.

## البنية

- `src/App.tsx`: الصفحة العامة والغلاف والشاشات والتدفقات التفاعلية.
- `src/data.ts`: الأدوار والملاحة والبيانات الوهمية وتسميات المسارات.
- `src/styles.css`: التصميم والاستجابة وRTL/LTR.
- `public/`: الأيقونة وبيان المسارات وصفحة 404.
- `.github/workflows/pages.yml`: البناء والنشر.
